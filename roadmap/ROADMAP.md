# React Roadmap

**Goal:** Learn how to build React components — first basic ones, then good enough for real products.

---

## Part 1 — Learn to build components

- [x] **1. Hello world** — get something on the screen
- [x] **2. Write HTML inside JavaScript (JSX)** — the React way of writing UI
- [x] **3. Make a component** — a function that returns some UI
- [ ] **4. Pass info into a component (props)** — like arguments to a function
- [ ] **5. Show a list of things** — loop over data and render it
- [ ] **6. Show or hide things** — based on a condition
- [ ] **7. Handle clicks and typing** — make the UI react to the user
- [ ] **8. Remember things (state)** — store values that change over time
- [ ] **9. Build a form** — inputs that work with state
- [ ] **10. Do something when the component shows up (effects)** — fetch data, etc.

By the end of Part 1: you can build a small working app from scratch.

---

## Part 2 — Make components good enough for real products

- [ ] **11. Design a clean component** — easy to use, hard to misuse
- [ ] **12. Add TypeScript** — catch mistakes before they happen
- [ ] **13. Make it accessible** — works for keyboard users, screen readers
- [ ] **14. Handle loading, empty, and error states** — not just the happy path
- [ ] **15. Style it well** — consistent look, easy to theme
- [ ] **16. Test it** — make sure it keeps working
- [ ] **17. Make it fast** — only when needed
- [ ] **18. Package it for reuse** — so other projects can use it

By the end of Part 2: you can build components that belong in a real product.

---

## How to use this

- Check items off as you go.
- Don't rush — really build something for each step.
