# UI Animation with React

A learning repo where I'm working through UI animation in React — from raw CSS transitions to spring physics with Motion. Public on purpose: each lesson lives as its own commit so the progression is visible.

## The plan

1. **CSS transitions** — hover, focus, the property/duration/easing triad.
2. **CSS keyframes** — multi-step animations without a library.
3. **CSS + React state** — toggling classes to trigger animations on state changes.
4. **Motion (Framer Motion)** — `animate`, `initial`, `exit`, `AnimatePresence`, `layout`.
5. **Gestures & physics** — drag, hover, tap, spring vs. tween.
6. **Advanced** — scroll-linked animation, shared layout transitions, SVG.

## Stack

- React 19 + TypeScript
- Vite
- Plain CSS first; Motion later

## Run it

```bash
npm install
npm run dev
```
